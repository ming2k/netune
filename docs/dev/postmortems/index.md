# Incident Postmortems

This directory holds blameless incident reviews. The authoring standard is [`../standards/postmortems.md`](../standards/postmortems.md); the template is [`TEMPLATE.md`](TEMPLATE.md).

Every Sev 1 or Sev 2 postmortem is a release gate. An action item is closed only when its verification — a test name, a gate, or an invariant — exists in the repository.
